Custom Field Groups (per-department)

For values that legitimately differ by which department initiated the RFQ - e.g. Department A's initiating officer name/designation, or its usual receiving store/authority, vs. Department B's. Each department can have one group. When a document is generated for an RFQ, the app looks up that RFQ's department, and any tag defined in that department's group overrides the matching global field above (a group only needs to define what's different - anything it doesn't set still falls back to the global value). An RFQ with no department, or a department with no group, just uses the global fields as-is.
